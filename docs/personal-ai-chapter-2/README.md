Phase 16 contracts and Gemini-backed migration are implemented locally; live provider compatibility remains unverified. This package records the accepted architecture and future scope; [ADR 0021](../decisions/0021-polyglot-persistence-foundation.md) and the [Phase 10 storage contract](phase-10-storage-ownership-and-access-patterns.md) define persistence ownership, and the [Phase 10 verification plan](phase-10-migration-cutover-and-verification-plan.md) records external acceptance checks. Phase 21's deterministic routing core is implemented locally; its guide/evidence document the code boundary and Phase 15 workflow gate. Phase 22 adds the bounded synthetic-public evaluation matrix and versioned quality evidence; live provider runs, Postgres migration/concurrency, output-retention rights, and Phase 15/deployed identity gates remain open. Phase 23 adds locally implemented deterministic quota-aware routing and paired synthetic evaluation; Postgres concurrency, live provider, account/privacy, and workflow acceptance remain open. Phase 24 onward remains future work. The [numbering map](NUMBERING-MAP.md) preserves original and regenerated phase identifiers.

The architecture assigns conversation/runtime timelines to DynamoDB, query-rich durable knowledge and vectors to Postgres/pgvector, and bulky immutable artifacts to a default-off GCS tier implemented locally in Phase 20. Phase 17R is implemented locally and gates Phase 18. Phase 18's system-owned endpoint registry snapshot belongs in Postgres under Phase 10 ownership. Phase 19's canonical usage ledger, quota reservations/windows, endpoint health, and compact aggregates belong in Postgres; separately retained operational attempt events belong in DynamoDB. Phase 21's canonical routing-decision observations also belong in Postgres. Migrations and provider/account preflight remain unapplied/unverified outside deterministic local checks; automatic workflow routing remains gated on Phase 15 acceptance.
